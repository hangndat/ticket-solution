# Brand fonts (Live Pulse v2 / Issue #489)

Self-hosted copies of `apps/web/fonts` so Expo never fetches Google Fonts at runtime.

| File | Family | Role |
| --- | --- | --- |
| `Sora-Variable.ttf` | Sora | Display / wordmark (replaces Syne v1) |
| `BeVietnamPro-*.ttf` | Be Vietnam Pro | Body / form / list |
