## Security

**Đã xét**

1. **API host / tenant confusion** — Published list dùng platform endpoint; wallet vẫn `getTenantId()` UUID; không invent tenant khi env trống.
2. **Fail-closed catalog** — API unreachable/invalid không map sang demo fixtures (`PUBLISHED_LIST_FAIL_CLOSED_MESSAGE`).
3. **OIDC / session** — Account giữ epoch guards, `logoutAndClearWalletArtifacts` + `endKeycloakSession`; sign-in clears APNS state best-effort.
4. **Push** — Không gọi lại system prompt khi `denied`; APNs registration qua existing `registerApnsDeviceToken` + session boundary (không diff secret vào app).
5. **Privacy WebView** — `PRIVACY_POLICY_URL` cố định `https://vemoki.com/privacy`; preflight `isTrustedPrivacyUrl`; `onShouldStartLoadWithRequest` → `shouldAllowPrivacyNavigation` (https + `vemoki.com` + path `/privacy*`); `incognito`, cookies tắt.
