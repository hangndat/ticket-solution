## Tóm tắt PR

- **Root cause (documented):** SSR `GatePage` giữ `app/loading.tsx` cho đến khi `requireSessionOrAuth` + `requireGateCapabilityOrHome` xong. Sau #682, guard chỉ refresh khi **không** có access cookie; access cookie còn nhưng JWT hết hạn → `forwardWithBearer` gửi Bearer stale → **401** → refresh → fetch lại, mỗi discovery dùng `STAFF_DISCOVERY_TIMEOUT_MS` **8s** → UAT ~12.2–12.4s khớp **hai bước upstream tuần tự** (401 retry), không phải client nav nhanh sau refresh tab.
- **Fix:** `isAccessTokenStaleForSsr` (`decodeJwt` exp + 30s skew, không verify chữ ký) trong `requireSessionOrAuth` → refresh **trước** discovery khi missing hoặc stale.
- **Observability:** `GATE_SSR_TRACE=1` → `[gate-ssr-trace]` chỉ `root`, tên bước, `+ms` / `total=ms`; trace optional qua `runGateStaffSsrGuards` → guards, `forwardWithBearer`, `refreshWebAccessToken`.
- **Tests:** `access-token-clock.test.ts` (fresh / past exp / garbage JWT); `staff-route-guard.test.ts` giữ policy capability (không diff trong PR).

## Security (chi tiết)

- **Stale check không bypass auth:** JWT giả exp tương lai trong cookie httpOnly chỉ có nếu server đã ghi token hợp lệ trước đó; tamper không verify → `isAccessTokenStaleForSsr` true hoặc API 401 → refresh/reject. Không tin chữ ký thay grant.
- **Trace ops:** Bật prod chỉ nên tạm thời; log không chứa path/query có secret (discovery path không in).
- **Admin / gate parity:** Stale refresh ở shared guard — không mở capability, chỉ giảm double-fetch.
