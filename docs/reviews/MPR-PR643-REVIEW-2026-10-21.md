## (1) Hành vi UI / idempotency — giữ nguyên

So sánh diff `admin-form.tsx`:

| Quy tắc | Trước / sau |
| --- | --- |
| Khóa idempotency | `reuseUnclearKey(attempt, fingerprint)` → `hook.keyFor(fingerprint)` — logic **identical** (module `idempotent-action.ts` copy 1:1 từ inline cũ) |
| Kết quả chưa rõ | `remember(..., next.kind === 'unknown')` tương đương `set*Attempt({ ..., unclear: next.kind === 'unknown' })` — **chỉ** `unclear: true` khi view `unknown` (timeout/network), không khi `ok` / `rejected` |
| Retry cùng fingerprint sau unclear | Reuse `existing.key` khi `unclear && fingerprint khớp` — không đổi |
| Success paths | Vẫn chỉ cập nhật editor/state khi `next.kind === 'ok'` (hoặc nhánh tương ứng từng luồng); **không** coi `unknown` là thành công |
| Approve/deny | Vẫn 2 attempt state tách biệt → 2 hook instance — hành vi giữ nguyên |

`useAdminScope`: `useState(initial*)` + `scope()` trim — tương đương `useState(initialTenantId)` / function `scope()` cũ.
