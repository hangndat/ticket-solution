## Threat cases và giới hạn

- Đã đối chiếu actor B / tenant khác / event khác / original session user khác → uniform 404; revoked membership/assignment hoặc thiếu active session → 403; original inactive nhưng session mới owned active → read allowed; corrupt session join → 404. Backend SQL dùng parameterized `$queryRaw` và `FOR SHARE`, không `assertOpenForGate`. Test không chứng minh HTTP end-to-end cho toàn matrix: HTTP runtime proof chỉ 401/200/404, còn PG tests gọi backend lookup trong `withTenant`.
- Receipt `CURRENT`, `UNDONE`, `TICKET_REVOKED`, `NO_LONGER_CURRENT` đều map historical `recorded` với tone unknown/non-admit; 404/network/auth giữ queued/unknown. Không phát hiện đường GET → fresh haptic/audio/admitted. Queue POST `APPLIED`/`DUPLICATE` là lane khác theo ADR18, không gộp với GET historical.
- Không coi preflight C01–C11 FAIL của draft là verdict của implementation; những điểm đã sửa được đánh giá từ source frozen. Thiếu native M10 restart OFFLINE→online cùng `clientEventId` và independent History/physical proof vẫn chặn acceptance riêng theo coordinator, không được waive bằng report security này.
