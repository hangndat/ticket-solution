## Refactor review (hành vi)

- **Export:** `useExportApi` giữ create → optional `exportId`, load status, download blob + `revokeObjectURL`; idempotency `unknown` reuse key — khớp monolith.
- **CS:** cooldown UI + server `RESEND_COOLDOWN`; copy «ACCEPTED/PENDING ≠ đã giao»; PII masked list/detail — giữ nguyên.
- **Redemption:** validation UUID/reason length; `decideAdmin` + idempotency per approve/deny.
- **Lifecycle:** impact confirm gate trước patch; `onBeforeLifecycleMutate` clear create/list/decision.
- **Effects:** `clearSpecialViews` effect phụ thuộc object API hooks (ref cập nhật mỗi render) — không gây vòng `setState` vô hạn; chỉ cập nhật ref callback.

## Security

| Chủ đề | Đánh giá |
| --- | --- |
| Authz / tenant scope | Mọi mutate vẫn gửi `scope()` / `tenantId` qua BFF; không bypass RLS phía client. |
| Idempotency abuse | Reuse key chỉ khi `unclear` + cùng fingerprint — không coi `unknown` là success. |
| CS / PII | Không log email thô; masked fields + permission denied surface. |
| Export download | Same-origin fetch, blob download, `noopener` anchor — không inject URL từ user input vào `href` (exportId encoded). |
| XSS | Section chỉ render label/interpreter text đã có; không `dangerouslySetInnerHTML` mới trong diff. |
| Slice | PR **không** sửa `src/oidc` / `src/bff` — tách auth layer (#640) tôn trọng. |
