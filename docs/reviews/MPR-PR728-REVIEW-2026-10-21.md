## Security

- Terminal path tách biệt login deep-link (`error=session_rejected` vs `next=`) → giảm redirect loop và accidental re-SSO khi refresh đã fail.
- Fail-closed: xoá session trước khi hiện notice guest; không echo `error` raw ra UI.
- Infra: tránh resolve nhầm host `api` trên shared nginx edge (collision cross-stack) — giảm rủi ro BFF gọi upstream sai.

**Known gap (nhỏ, không chặn PASS):** không có E2E mô phỏng full SSR double-401 → notice trên `/gate`; hành vi khóa bởi unit test terminal path + pattern review refresh route + `/auth` stub.
