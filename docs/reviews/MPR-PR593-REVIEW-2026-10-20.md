## Security

**Đã xét**

1. **Bearer / gate API** — Scan/reconcile đi qua existing `runScan` / `reconcileOp`; không bypass server gate; scope từ MeEvents + persisted selection validated types trong `readPersistedStaffGateScope`.
2. **SecureStore** — Workspace v2 + legacy scope keys namespaced per `userId`; không ghi full QR/raw vào durable store (ops structure từ `recoverOps`).
3. **Staff eligibility** — Tab staff hidden unless `staffWorkspace` hoặc resolved `staffEligible`; `refreshGateEvents` clears state khi `staffEligible !== true`.
4. **Logging** — `traceGateScan` dev-only; device history dùng truncated ticket id.
5. **Logout path** — `logoutStaff` → `logoutAndClearWalletArtifacts` + `endKeycloakSession`; offline queue `clearForUser` khi có `userId`.
