## AC Issue #614 — đối chiếu

### (1) `resolveCredential()` — refresh unreachable vs auth reject

- `ensureFreshAccessToken()`: `reason === 'network'` → `{ status: 'unreachable' }` **không** `invalidate` / **không** `store.clear()`.
- `reason === 'auth'` (invalid_grant / revoked qua `oidc-refresh` `isAuthFailure`) → `invalidate(signed-out)` + `clear()` — vẫn logout thật.
- `resolveCredential()` khi verified:
  - `token` — bearer mới hoặc còn hạn.
  - `refresh-unreachable` — IdP không refresh được (mạng).
  - `unavailable` — không verified hoặc auth refresh fail (đã signed-out).
- **Không** trả access token hết hạn khi refresh network-fail (fix S1 PR #613).

Tests: `refresh auth failure signs out…`, `refresh network failure… signals unreachable`, `restore refresh auth/network…`.

### (2) `my-tickets` + `decideTicketSyncApply`

- `VerifiedWallet.refresh`: `resolveCredential()`; `refresh-unreachable` → skip API, probe giả `unreachable` + `credentialRefreshUnreachable: true`.
- `decideTicketSyncApply`: nếu probe `unauthorized` **và** flag → coi như `unreachable` → `offline-cache` khi có cache hợp lệ; **không** `logoutAndClearWalletArtifacts`.
- 401 thật (không flag): vẫn `action === 'unauthorized'` → logout + xóa wallet artifacts.

Test: `unauthorized with credential refresh unreachable uses offline cache (no logout)` + test unauthorized gốc không đổi.

### (3) Vòng lặp retry / log refresh token

- `refreshInFlight` single-flight — không storm refresh.
- `oidc-refresh.ts`: comment + implementation không log token; lazy import AuthSession.
- Không thêm `console.*` token trong diff.

### (4) Consumer `getCredential()` khác

| Consumer | Hành vi khi `refresh-unreachable` (verified, credential còn store) |
| --- | --- |
| `getCredential()` | `null` (không trả expired bearer) — **đổi** so PR #613 |
| `my-tickets` | Dùng `resolveCredential()` — **đúng AC** |
| `account.tsx` `refreshMe` | `getCredential()` null → copy “Đăng nhập lại khi có mạng” — **không** logout |
| `staff-eligibility` | `!bearer` → `reset()` ẩn tab staff — **không** logout wallet |
| `staff-gate` `resolveGateAuth` | `getCredential()` null → thử `restore` → vẫn có thể báo “Chưa có phiên…” dù UI verified — **UX gap nhỏ**, ngoài AC #614 (wallet logout oan) |
| account-deletion, push, redeem, … | `getCredential()` null → fail operation, không auto-logout wallet |

**Kết luận:** AC #614 tập trung wallet false logout — đạt. Consumer khác: an toàn hơn (null thay expired bearer); gate auth message có thể misleading khi IdP down — không blocker.
