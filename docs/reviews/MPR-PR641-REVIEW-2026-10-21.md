## (1) APNs `TicketIssued` ngoài transaction & fence lease

**Thiết kế (mirror H2 email):**

1. Tx `prep`: `fenceOutboxToProcessing` → chuẩn bị email.
2. `email.sendTicketIssued` **ngoài** tx.
3. Tx `outcome`: ghi notification email; nếu **không** có own-property `apns` → `markOutboxCompleteFenced` và xong.
4. Nếu có `apns` (kể cả `null` = fail-closed có chủ đích): trả `push_pending` → `deliverTicketIssuedApns` (list device + insert notification push trong tx ngắn; `apns.send` ngoài tx; ack push per device trong tx follow-up) → `markOutboxCompleteFenced`.

**Crash giữa gửi APNs và ghi DB:** Outbox vẫn `PROCESSING` / chưa `COMPLETE` cho đến bước fence cuối; notification push có thể `PENDING` hoặc đã `ACCEPTED` tùy thời điểm crash. Retry outbox → idempotency qua `business_key` push (`ticket:{id}:issued:push:{deviceId}`) và skip khi state `SENT`/`ACCEPTED`. **At-least-once push** vẫn chấp nhận được (cùng class limitation #626); PR không thêm ADR mới — nên ghi limitation trong docs/ADR sau nếu cần audit trail.

**Fence lease:** `markOutboxCompleteFenced` sau push dùng cùng `lease_owner` / `lease_token` như email path — phù hợp H3.

**Gap test:** Không có test DB mới cho APNs ngoài tx / crash-at-least-once; chỉ regression gián tiếp qua `cs-export` (xem §Checks).

## (2) `relayOutboxOnce` — opt-in `apns` & fail-open/closed

| Caller | Hành vi |
| --- | --- |
| **Omit** `options.apns` (worker `APNS_ENABLED` false → `relayOpts()` không có key) | Skip push hoàn toàn; complete outbox sau email — **đúng** “N1-only”. |
| **`apns: null`** (explicit, ví dụ test fail-closed) | Opt-in fail-closed: có device token → `apns_misconfigured` → job failed/retry; **không** silent skip. |
| **Worker `APNS_ENABLED` true** | `createApnsAdapter` validate key lúc construct — misconfig **fail-closed lúc startup**, không “mất push im lặng”. |

**Thay đổi so với trước:** `relayOutboxOnce` trước luôn truyền `apns: options?.apns` (key tồn tại với value `undefined`), khiến path push fail-closed kích cả khi caller không chủ đích opt-in. PR **sửa** đúng hướng worker/tests.

**Regression phát hiện:** Với `apns: null` và path “đã xóa device”, `relayOutboxOnce` vẫn trả `failed: 1` — `cs-export.test.cjs` assertion `no-device path must not fail-closed` (≈ line 877). Xem §Checks.
