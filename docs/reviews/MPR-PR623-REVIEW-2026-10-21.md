## Security review

| Threat / abuse | Kết luận |
| --- | --- |
| CSRF trên BFF mutation | Origin bắt buộc; không dùng `Sec-Fetch-Site` thay Origin (`origin.test.ts`). **PASS** |
| Host-header / X-Forwarded spoof cho redirect OIDC | `resolvePublicOrigin` chỉ `WEB_PUBLIC_ORIGIN` (prod) hoặc request URL origin (dev). **PASS** |
| Session fixation / cookie over HTTP prod | `secure: NODE_ENV === 'production' \|\| AUTH_COOKIE_SECURE`. **PASS** |
| CSV bomb / polyglot upload | Early reject khi `Content-Length` > max+overhead; post-parse `file.size` + MIME/extension. **PASS** (xem limitation) |
| CSP bypass inline script | Prod vẫn `unsafe-inline` script (Next/Ant Design pattern, khớp portal). **PASS with known gap** (hardening nonce sau) |
