## Security

**Đã xét**

1. **Redeem code handling** — Draft chỉ in-memory; debug `redact*` không xuất plaintext code; không persist AsyncStorage trong diff.
2. **Session boundary** — Resume/drop gắn `parkedUserId` / `parkedGeneration` + `isEpochCurrent`; account switch clears tenant draft (test + runtime).
3. **Auth gate** — Submit/reconcile/status refresh yêu cầu bearer + epoch hiện tại; `AUTH_CODES` clears decision sau verify.
4. **Dev / UAT surface** — Fixture + UAT session fail-closed trên Release unless explicit `EXPO_PUBLIC_ALLOW_*=1` (documented local-only).
5. **Logout hygiene** — `logoutAndClearWalletArtifacts` fail-closed aggregate errors; clears guest claim, tenant redeem draft, sign-in return, notification tap intent (existing C-I/C-N patterns).

**Known gap**

| Mức | Finding |
| --- | --- |
| Low | `logoutAndClearWalletArtifacts` clears `clearRedeemDraftIntent()` but **not** `clearGlobalRedeemDraftIntent()`. Pre-login global park (`parkedUserId: null`) có thể resume sau khi user khác đăng nhập trên cùng process (shared device), trong khi tenant draft đã bị xóa khi logout. **Harden:** gọi `clearGlobalRedeemDraftIntent()` trong cùng block logout; thêm unit tests global mirror tenant (`redeem-draft-intent.test.ts` hiện chỉ cover tenant store @ SHA). |

**Không thấy** API auth bypass, secret leak, hoặc prod enablement của UAT/fixture routes trong diff.
