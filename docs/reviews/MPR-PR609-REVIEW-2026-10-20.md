## Fix assessment

### `randomId` / Hermes-safe

- PR **không** viết fallback mới trong `gate-scan.ts`; wire default `createId` sang helper có sẵn `apps/mobile/src/lib/random-id.ts`.
- Helper: ưu tiên `globalThis.crypto.randomUUID` khi có; else `require('expo-crypto').randomUUID()` — đúng class Hermes (không có global `crypto`).
- Helper đã dùng ở `staff-gate-workspace-context.tsx` — reuse, không invent polyfill ad-hoc.

### Regression test

- Test mới: `default createId persists deny after session open without injected createId` — mô phỏng `/sessions` 200 + `/reservations` 404, **không** inject `createId`; assert `staffSessionId` giữ session, `phase === 'denied'`, `ops[0].id` tồn tại.
- Cover đúng **wiring** default path (trước đây throw Hermes → không persist). **Không** mock xóa `globalThis.crypto` để ép nhánh expo-crypto trong node:test — gap unit (xem Known gaps).

### `offline-queue.ts`

- Chỉ đổi default `opts?.createId ?? (() => crypto.randomUUID())` → `randomId`.
- Không đổi partition / persist / replay / clientSeq. `offline-queue.test.ts` vẫn pass (inject `createId` trong fixtures không đổi hành vi).
- Rủi ro hành vi offline: thấp — cùng UUID string contract; Hermes trước đây throw khi enqueue mặc định → giờ an toàn.
