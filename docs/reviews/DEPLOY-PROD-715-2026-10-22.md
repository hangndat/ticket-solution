3. Ghi `.deploy-sha` = target SHA.
4. **web:** `pnpm --filter @ticket/web build` trong `vemoki-runtime:local` → `docker compose restart web`.
5. **api:** `tsc` contracts → `pnpm --filter @ticket/backend build` → `pnpm --filter @ticket/api build` → `docker compose restart api`.

Lệnh rút gọn (trên VPS, `cd /opt/vemoki/src/infra/deploy`):

```bash
docker run --rm --env-file /opt/vemoki/.env -v /opt/vemoki/src:/app -w /app vemoki-runtime:local \
  sh -c 'pnpm config set store-dir /app/.pnpm-store && pnpm config set package-import-method hardlink && pnpm --filter @ticket/web build'
docker compose --env-file /opt/vemoki/.env restart web

docker run --rm --env-file /opt/vemoki/.env -v /opt/vemoki/src:/app -w /app vemoki-runtime:local \
  sh -c 'pnpm config set store-dir /app/.pnpm-store && pnpm config set package-import-method hardlink && pnpm --filter @ticket/api exec tsc -p ../../packages/contracts/tsconfig.json && pnpm --filter @ticket/backend build && pnpm --filter @ticket/api build'

```
