## (2) Behaviour-preserving — Health / Me / Identity / `resolveIdentity`

| Thành phần | Đánh giá |
| --- | --- |
| `HealthController` | `GET` trả `{ status: 'ok', service: 'api', version: '0.1.0' }` — giống `app.ts` trên `main`. |
| `IdentityService.me` | `bootError` → throw; thiếu verifier/users → `OIDC_MISCONFIGURED`; luồng verify + upsert + `MeResponse` — giống `main`. |
| `MeController` | Bắt `IdentityError` → `toHttpException` — giống `main`. |
| `toHttpException` | `identityErrorHttpStatus(error.code)` + body `ApiError` — giống `main`. |
| `resolveIdentity` | Logic từng nhánh (`identityBootError`, inject test, fail-closed, OIDC/DB bootstrap) — **byte-for-byte cùng thân hàm** với `main` (chỉ thêm import/`export`). |
| `CreateAppOptions` | Type fields giữ nguyên; chuyển sang `app-options.ts` với import type từ `@ticket/backend`. |
| `createApp` wiring | `useValue: new IdentityService(...)`, controller order, `resolveIdentity(normalized)` — giữ như trước refactor. |

**Mã lỗi / HTTP (#625):** `identity-http-status.ts` **không đổi** trong PR. `OIDC_MISCONFIGURED` và `OIDC_UNAVAILABLE` → **503**; test `me.test.cjs` xác nhận 503 + code `OIDC_MISCONFIGURED` khi `identityBootError`.

**Kết luận (2): Đạt** (refactor thuần, hành vi giữ nguyên trong phạm vi đã tách).
