## Security (tenant / RLS / public catalog)

**Threat / abuse cases đã xét**

1. **Draft / unpublished / wrong version leak** — Query + RLS double-gate (`published_config_version`, `published_at`, `content_status`, join version). Test: draft `draft-only` không xuất hiện cho đến khi `publishEventConfig`; sau publish có trong platform list.
2. **Cross-tenant data via platform role** — `withPlatformRole` → `SET LOCAL ROLE ticket_platform_runtime`; policies hẹp trên `events` / `event_config_versions`; application query vẫn filter PUBLIC/PUBLISHED (defense in depth).
3. **Admin / internal field leak** — List path maps summary only; không serialize full `payload` ra HTTP (dù SELECT payload cho brand join logic — mapper whitelist).
4. **Cursor injection / tampering** — Parameterized SQL; cursor decode validates UUIDs; malformed → `PublishedEventsError` → HTTP 400 `INVALID_CURSOR` tại Nest layer.
5. **Inactive tenant enumeration** — `INNER JOIN tenants … status = 'ACTIVE'`.
6. **Authz** — Endpoint cố ý public (catalog marketing); không mở admin paths; deny-by-default không bị bypass qua platform list.

**Không blocker.**
