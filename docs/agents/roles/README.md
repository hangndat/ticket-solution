Agent/model/effort theo [routing](../policies/routing.md) và [cost catalog](../cost-catalog.md); catalog role không duy trì bảng provider riêng. Role, vendor, Cost tier và persona là các khái niệm riêng.

Coordinator chuẩn bị spec có Role ID/file; reviewer nhánh B khác implementer. UI task theo [UI workflow](../ui-workflow.md). BA/PD chỉ khi AC/handoff chưa đủ; architect khi quyết định boundary/contract/invariant cần giải quyết. Không spawn đủ roster cho mọi Task. Nguồn tham khảo upstream giữ nguyên provenance, không phải policy vận hành.
